# Full-DFT DeltaSCF/ROKS companion manuscript

This directory contains the first independent draft of the full-DFT
DeltaSCF/ROKS paper. It is intentionally separate from the semiempirical
MOUSE OO-CID manuscript. The draft reuses the qualified implementation notes,
tables and figures from `mouse_orbital_optimized_dft` and does not claim a
completed ORCA/PySCF accuracy benchmark.

The implementation source and qualification archives remain in
`packages/matrix-pyscf` and `qualification/dft_roks_response_20261102`.
