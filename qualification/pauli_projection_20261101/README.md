# General-nonlocal representability diagnostic

Unlike the earlier eightfold-Coulomb projection, this diagnostic permits a
general nonlocal Hermitian, particle-interchange-symmetric spatial interaction.
Only the Pauli-incompatible fully symmetric component of charge+spin response
is removed. Three algebraic tests verify reconstruction, the nearest-response
condition, the HF/one-electron limits and exact FCI spin/Hermiticity properties.

The small CAS(6,6) spectra for PBE0 and coherent M06-2X do not resolve the
accuracy problem. No orbital optimization or nuclear derivative implementation
is promoted from this branch. The complete spectra, weak-transition diagnostics
and failed fixed assignment gates remain preserved on Oracle.
